语音识别

B 站没有原生字幕时，Suikan 随看 会用下面选择的引擎给视频生成带时间戳的字幕。

Suikan 随看 会下载当前B站音轨，上传到百炼48小时临时空间，并使用 Fun-ASR 生成带时间戳字幕。 获取百炼 API Key。

启动 start_whisper_server.bat 后，Suikan 随看 会下载音轨 交给本地 Whisper 转写，再调用 AI 校正专有名词。

Whisper 转写 + AI 校正后的字幕会保存到这里（按 BV 号缓存）。 下次再打开同一视频会直接读缓存，不再跑 Whisper。

AI provider

Suikan 随看 uses GLM (Zhipu / Z.AI) for overviews, explanations, translation, and note polishing. Default model: glm-4.6. Pick the API type that matches your key — the two endpoints have different keys that are NOT interchangeable. Create a Zhipu API key.
