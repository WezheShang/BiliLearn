bilidown 设置

密钥保存在当前 Chrome 配置中，只在使用 AI 功能时发送给 minimax。 本扩展没有开发者服务器或数据分析。

请点击保存设置，否则您的修改将不被保存。

语音识别

B 站没有原生字幕时，bilidown 会用下面选择的引擎给视频生成带时间戳的字幕。

bilidown 会下载当前B站音轨，上传到百炼48小时临时空间，并使用 Fun-ASR 生成带时间戳字幕。 获取百炼 API Key。

启动 start_whisper_server.bat 后，bilidown 会下载音轨 交给本地 Whisper 转写，再调用 AI 校正专有名词。

本地环境准备 检查本机 Python / 依赖 / 服务是否就绪
  1. 本机装有 Python 3.10+（bilidown 不自带 Python，也不会替你安装）
  2. 安装 Whisper 依赖到你的 Python——检查后这里会给出针对本机的确切命令，装不装由你决定
  3. 双击扩展文件夹里的 start_whisper_server.bat，保持窗口开着 打开扩展管理页，查看文件夹路径
  4. 点「检查系统」，全部 ✓ 即就绪
    http://127.0.0.1:7860

    Whisper 转写 + AI 校正后的字幕会保存到这里（按 BV 号缓存）。 下次再打开同一视频会直接读缓存，不再跑 Whisper。

    通知

    任务完成后弹系统级通知。任务本体不受影响——关闭后只是不弹卡片。

    完成后弹通知

    通知会显示视频标题，点击会聚焦已打开的视频标签页。 总结和概览是同一类工作（都是对转录后的字幕做 LLM 处理）， 因此统一一个开关。

    AI provider

    bilidown uses minimax for overviews, explanations, translation, and note polishing. Create a minimax API key.

    bilidown uses DeepSeek for overviews, explanations, translation, and note polishing. Create a DeepSeek API key.

    bilidown uses GLM (Zhipu / Z.AI) for overviews, explanations, translation, and note polishing. Default model: glm-4.6. Pick the API type that matches your key — the two endpoints have different keys that are NOT interchangeable. Create a Zhipu API key.
