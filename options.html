欢迎使用 bililearn — 快速上手

  1. 默认行为 — 当前只会加载并显示 B 站官方字幕（人工或 AI 翻译）。没有官方字幕的视频不会自动转写。
  2. 想要本地转录？ — 当你打开一段没有官方字幕的视频时，请到下方「语音识别」切到 Whisper（或接入其他模型）。首次启用 Whisper 需要本机装 Python + Visual C++ 运行时 + faster-whisper，详情点「检查系统」看分步指引。
  3. 想要 AI 总结/概览？ — 需要在下方「AI provider」里选一个模型并填入 API key。没有配的话，bililearn 只能给你看字幕，不会总结。

AI provider

用于视频总结 + 概览。选择一个模型并填入 API key。 没有配的话，bililearn 只能给你看字幕，不会总结。

用你自己的代理：把请求发到一个 OpenAI-compatible 的 endpoint， 自行替换 {"{{model}}"} / {"{{baseUrl}}"} 之类的占位符。 不会上传你的 key 到任何官方服务。

语音识别

B 站没有原生字幕时，bililearn 会用下面选择的引擎给视频生成带时间戳的字幕。

用 MiniMax 云端 ASR 给没有官方字幕的视频生成字幕。 账户余额在 minimax 后台查看，按字符计费；本地不占任何资源。

当前 MiniMax 语音识别只发布了一个模型 asr-1.0， 选它就好；后续如果官方上线更多模型这里会自动加上。

B 站视频有官方字幕时会自动使用——你**不需要**装 Whisper。 本设置仅在你需要转录**没有官方字幕**的视频时使用；按需安装即可。

本地 Whisper 需要 5 项依赖，每项各占一行。在「语音识别」下拉选 Whisper 或点「检查系统」会逐行检测：装好的打 ✓（带版本），缺的标 ✗ 并在该行右侧 给出对应的安装或启动按钮。
