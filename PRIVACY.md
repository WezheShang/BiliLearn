# Privacy

Suikan 随看 has no account system, analytics, telemetry, advertising, or developer-operated server.

- The extension reads public video metadata and available subtitle tracks from Bilibili.
- Your minimax API key, notes, settings, and recent cache entries are stored in `chrome.storage.local`.
- When an AI feature is requested, the relevant transcript and video context are sent directly from the extension to minimax.
- No API key is included in the source code or release package.

Bilibili and minimax process requests under their own terms and privacy policies. Remove all local extension data from Settings before uninstalling if you do not want Chrome to retain it.
